### A little about me

I'm a frontend engineer with a background in technical and team leadership. My focus is hands-on engineering: shaping application architecture, building interfaces, and connecting the pieces that make a product work.

I've worked on e-commerce, education, mapping tools, and fintech products. I enjoy the details behind a smooth user experience — predictable data flows, fast rendering, reliable authentication, and code that's easy to change.

### What I bring to a product

- **Structure that supports growth.** Frontend architecture, reusable components, and clear boundaries between UI, data, and business logic.
- **Care for the user experience.** Performance, Core Web Vitals, server rendering, and technical SEO.
- **Work across the stack.** API integrations, custom OIDC authentication, Node.js, and backend contributions in Go.
- **Care beyond the release.** Meaningful tests, production monitoring, automated checks, and thoughtful code reviews.
